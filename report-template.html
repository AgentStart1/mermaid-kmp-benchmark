__METHOD__

这是 Kotlin 源码与 Rust KMP 发布制品在 JVM 上的热态测量，不代表移动端或 Kotlin/Native 性能。mermaid-native 为公共源码的 JVM 适配，上游没有官方桌面 JVM 目标。Rust KMP 使用 alpha5 发布制品，SVG 耗时包含 JNI 调用。内存分配数据仅覆盖 JVM 堆，不含 Rust 原生堆，不能作为两者总内存比较。文本测量、布局和最终输出不同，速度不等于兼容性或画质。不同阶段不参与同一个排名。
